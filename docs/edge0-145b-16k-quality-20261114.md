# Edge0-145B Q3_K at 16K: fast, but unusable as a coding agent

Edge0-145B Q3_K produced strong raw throughput on the RTX 5070 Ti, but the 16K OpenCode evaluation failed badly. Across six frozen SWE-bench Verified issues with three attempts each, it completed **0 of 18** attempts under the strict agent criterion. Only **2 of 18** patches passed their independent held-out tests, and 15 attempts left no patch.

## Configuration

- Edge0-145B Q3_K with Edge0-Strata 0.1.55
- 16,384-token context capacity
- 1,100 MiB VRAM reserve
- OpenCode 1.18.16 with workflow guidance
- 18 attempts over six frozen issues
- 1,200-second task limit

The two successful patches were `pytest-dev__pytest-6202` trial 0 and `psf__requests-5414` trial 2. The first passed all seven held-out tests but later hit a context overflow at 18,294 prompt tokens. The second passed all 21 held-out tests but ended at the generation limit, so neither counted as a complete autonomous agent run.

## Verdict

At 16K, this setup is **not viable for autonomous coding**. The engine is fast, but OpenCode repeatedly exhausted the context window, compacted conversations, or reached output limits before producing a finished patch. The run does not establish Edge0 quality at larger contexts. It establishes that the tested 16K configuration is a poor use of 98GB of local model storage for this workload.

GPU energy is device-wide and excludes CPU and wall power. Process RSS can include mapped and shared memory. Raw task traces remain local and are excluded from Git.
